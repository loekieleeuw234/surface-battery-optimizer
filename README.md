## Quick start

1. Download the script
2. Run it
3. Wait
4. Watch the panic

No install. No dependencies. No admin rights needed for the basic shutdown.

## Warning

**Anything open and unsaved is gone.** Word documents, Photoshop projects, half-written code, that form you were 90% done filling in. If it matters, save it. If you didn't save it, that's a you problem.

## Compatibility

- Windows 10
- Windows 11

Nothing else. This is not a cross-platform tool and has no interest in becoming one.

## Configuration

Both knobs are one-liners at the top of the script:

| Setting | Default | Notes |
|---|---|---|
| Minimum delay | 10 seconds | Lower bound of the random window |
| Maximum delay | 90 seconds | Upper bound of the random window |

Want it crueler? Widen the window. Want it instant? Set both to the same number.

## Why "Surface Battery Optimizer"

Because that name sounds boring and official, which is exactly what you want. Nobody suspects a thing called *Surface Battery Optimizer*. Nobody backs up their work before running one.

## FAQ

**Does it save anything first?**
No.

**Can it be cancelled once the message appears?**
Only if you're fast.

**Will it close my programs properly?**
It shuts the machine down. Whatever survived, survived.

**Is it reversible?**
The shutdown is. The lost work isn't.

**Can I run it on someone else's machine?**
That is the entire point.
